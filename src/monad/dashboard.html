A2A Pay
Network Monad Protocol x402 v1 · exact Settlement EIP-3009

Per-request payments between autonomous agents, settled on Monad

Each HTTP request to a paid agent returns 402 Payment Required. The buyer signs a transfer authorization off-chain, and the seller verifies it, settles it on-chain at its own gas expense, and then serves the response. The analyst agent is both a seller and a buyer. Every report it issues cites the on-chain payment for its input data.

05Controls

The seller pays gas for every settlement, so it checks each payment before submitting it.

5.1
Exact terms

Amount, recipient, token contract, and chain are checked against the seller's own quote. The token and chain are bound into the EIP-712 signature.

5.2
Single-use nonces

The seller issues each nonce, binds it to one resource and price, and burns it before submission. EIP-3009 enforces it again on-chain.

5.3
Simulation first

Unfunded or invalid authorizations are rejected in simulation, so a failed payment costs the seller no gas.

5.4
Buyer policy

Budget, per-call cap, and payee allow-list are enforced before signing. This is why the third request above is declined.
